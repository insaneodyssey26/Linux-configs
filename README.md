# Linux Configs

Dotfiles and configurations for Linux development environment.

## Contents

- `.bashrc` - Bash shell configuration
- `.gitconfig` - Git configuration and aliases
- `Fish/config.fish` - Fish shell configuration
- `Kitty/kitty.conf` - Kitty terminal emulator settings
- `Ghostty/config` - Ghostty terminal configuration
- `Starship/starship.toml` - Starship prompt configuration
- `Starship/starship2.toml` - Alternative Starship configuration
- `fastfetch/config.jsonc` - Fastfetch system info display (main)
- `fastfetch/small.jsonc` - Fastfetch compact display
- `config/fish/config.fish` - Additional Fish configuration
- `config/fastfetch/` - Duplicate Fastfetch configs
- `setup/setup.sh` - Setup script (incomplete)

## ⚠️ Warning

**Do not run the setup script (`./setup/setup.sh`).** The script is incomplete and will seriously mess up your system configurations. Review and copy files manually instead.

## Installation

1. Clone the repository
2. Review configurations in `dotfiles/` directory
3. Copy desired files to your home directory
4. Restart shell/terminal

## Requirements

- Linux
- Bash or Fish shell
- Git
